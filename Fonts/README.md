# Lyra fonts

Everything in this folder is a font Lyra can use. Lyra registers every font file here at launch
(from `Fonts/` next to the project while developing, from `Resources/Fonts` inside the packaged app),
and the picker lists them first, under **Lyra Originals** and **Lyra Hand-Drawn**.

All fonts are original designs, released under the **SIL Open Font License 1.1**. The license and
copyright text is stored inside every font file (name table) and in `LICENSE.txt`, so a font keeps
its license when it is copied on its own. You may use, change and redistribute them under that license.

## What is in here

| Path | What it is |
|---|---|
| `Lyra*-Regular.ttf` | The fonts themselves (one file per font, named after its PostScript name) |
| `LICENSE.txt` | The SIL OFL 1.1 notice for the whole set |
| `specimens/` | Specimen images of the generated originals |
| `drawn/` | Source for the hand-drawn fonts: one folder per font with its Python build script, README and specimen. Treated as read-only input by the tools; see below |

There are two families of fonts, made in two different ways.

### Lyra Originals (generated by code)

Eight display fonts generated by `Tools/FontFactory`, a small Swift package with no dependencies. They are
not derived from any other font. Their ids are fixed (the app keeps the list in `FontCatalog.originals`).

### Lyra Hand-Drawn (designed with an AI design tool)

The rest of the `Lyra*` fonts were designed with an AI design tool (an AI design tool), one font at a time,
from the prompts in `Docs/font-prompts/` (see `Docs/FontPrompts.md`). The tool returns a finished `.ttf` plus
the Python script that builds it (fontTools, skia-pathops, numpy, Pillow; deterministic). Those scripts, per-font
READMEs and specimens live in `drawn/<Name>/` and are kept as source so anyone can rebuild or change a font.
Finished files are copied from `drawn/` into this folder by `Scripts/install-fonts.sh`.

The hand-drawn list is **not hard-coded**: every `Lyra*.ttf` in this folder that is not one of the eight
generated originals becomes a "Lyra Hand-Drawn" entry (id = PostScript name, name = family name, sorted by name).

## Adding a font

**To the project (for everyone who builds Lyra).** Drop the finished `.ttf` into `Fonts/drawn/<Name>/` (or anywhere),
then run:

```bash
Scripts/install-fonts.sh                   # audits and installs everything in Fonts/drawn
Scripts/install-fonts.sh path/to/My.ttf    # or specific files and folders
Scripts/install-fonts.sh --check           # only audits the fonts already in Fonts/
```

The script skips half-written `*.tmp*` files and unreadable files, audits each font through CoreText, and copies
only the passing ones into `Fonts/` (replacing an older copy with the same file name; `Fonts/drawn` is never
modified). It prints a table of what was installed, updated or skipped, and why. The audit requires:

- a PostScript name that is unique across `Fonts/` and a family name
- a copyright string and the SIL Open Font License text in the name table
- every character of A-Z, a-z, 0-9, the punctuation `. , ! ? ' " - : ; & ( ) / # @ % + = $ * _ ~` and the Latin accents
  `áàâäãåéèêëíìîïóòôöõúùûüñçýÿ` in both cases
- unitsPerEm 1000, ascent about 800, descent about 200
- no glyph above 1.0 em or below -0.4 em (2 units of rounding allowed), and positive advances

The same checks run in the test suite over every file in this folder (`FontFolderAuditTests`), so a font that
is dropped in by hand is still checked. No code change is needed for the font to show up in the picker; a theme for
it is required by the tests (see above).

**In the app (for one person).** Use **Add Custom Font...** at the top of the font picker (or the menu item), or drag font
files onto the picker. `.ttf`, `.otf`, `.ttc` and `.otc` are accepted, several at once. Lyra copies them to
`~/Library/Application Support/Lyra/Fonts`, loads them straight away and again at every launch, and lists them under
**My Fonts**. Right-click a font there to remove it or show it in Finder. A font that macOS or Lyra already has is
reported as a duplicate instead of being added twice. A theme that names a font which is no longer installed falls back to
the system font, and the picker says so.

## How fonts are discovered

`FontCatalog.registerBundledFonts()` looks, in this order, in the packaged app's `Resources/Fonts`, in the folder
named by the `LYRA_FONTS_DIR` environment variable, and in a `Fonts/` folder found by walking up from the executable
or the working directory (the project, while developing). Every font file there is loaded for the process (half-written
`*.tmp*` files are ignored). The catalog (`FontCatalog.originals`, `.handDrawn`, `.featured`) is built from what it finds
and refreshed when new files are registered. `Scripts/make-app.sh` copies `Fonts/*.ttf` and `LICENSE.txt` into the app bundle.

## How they are made

`Tools/FontFactory` is a small Swift package with no third-party dependencies:

1. `Skeleton.swift` draws the alphabet once as block-letter centerlines, each corner carrying a
   rounding factor. `Pixel.swift` holds the bitmap font's grid.
2. `Styles.swift` gives each font its own stroke weight, proportions, corner treatment (round,
   chamfered or square), slant, line ends (round, spiked, tapered, padded) and extras (serrated
   teeth, corner thorns, stencil cuts).
3. `Stroker.swift` turns the centerlines into filled outlines. Every piece is a clockwise
   polygon, so overlapping pieces fuse under the non-zero winding rule.
4. `TTFWriter.swift` writes a real TrueType file (`head`, `hhea`, `maxp`, `OS/2`, `hmtx`, `cmap`,
   `loca`, `glyf`, `name`, `post`).

Output is deterministic: running the tool again gives byte-identical files.

## Regenerate

```bash
swift run --package-path Tools/FontFactory fontfactory --out Fonts --specimens Fonts/specimens --overview Fonts/specimens/_overview.png
```

`--only "Forge"` regenerates one font. Run the factory's tests with
`swift test --package-path Tools/FontFactory`; they decode the generated files independently and
check the table directory, checksums, glyph data, character map, winding direction and that
macOS CoreText loads every font and draws every character.

Regenerate the originals (output is deterministic, byte-identical on every run):

```bash
swift run --package-path Tools/FontFactory fontfactory --out Fonts --specimens Fonts/specimens --overview Fonts/specimens/_overview.png
```

`--only "Forge"` regenerates one font; `swift test --package-path Tools/FontFactory` runs the factory's own tests.

To rebuild a hand-drawn font, run its script from its folder, for example `cd Fonts/drawn/Script && python3 build_script.py`
(each folder's README names the exact script and the Python packages it needs), then run `Scripts/install-fonts.sh`.

## Tests

- `swift test --package-path LyraApp --filter FontFolderAuditTests` audits every font file in this folder.
- `HandDrawnFontTests`, `OriginalFontTests` and `FeaturedFontTests` check the catalog, coverage, metrics, rendering and licensing.
- `swift test --package-path LyraCore --filter ThemeCollectionTests` checks that every font here has exactly one theme.
