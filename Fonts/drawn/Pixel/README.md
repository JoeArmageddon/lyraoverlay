# Lyra Pixel Drawn

Files: `LyraPixelDrawn-Regular.ttf`, `build_pixel.py` (generator; also needs `lyra_fontkit.py`), `specimen.png`.
Rebuild: `/tmp/fontvenv/bin/python build_pixel.py` (needs fontTools, skia-pathops, numpy, Pillow).

Family "Lyra Pixel Drawn", style Regular, PostScript "LyraPixelDrawn-Regular". 1000 upm, hhea/typo ascender 800, descender -200, lineGap 0, winAscent 900,
winDescent 250, USE_TYPO_METRICS set, capHeight 700. Quadratic TrueType outlines, merged contours, outer contours clockwise.
Covers A-Z a-z 0-9, the required punctuation and Latin accents (see brief), plus NBSP and dotless i.
All outlines are original, generated by code; nothing traced or derived from any typeface.

## Design spec
Chunky bitmap face on a strict 100-unit square pixel grid. Capitals are 7 pixels tall (700) and 5 wide, lowercase 5 pixels
(500) with 7-pixel ascenders and 2-pixel descenders, proportional advances (glyph width + 1 pixel). Each pixel is an exact
100x100 square; adjacent pixels are merged by boolean union so there are no seams.

- Numerals: dotted zero (distinct from O), all other digits 5x7.
- Accents: 2-pixel marks, 1-pixel gap above the letter. Capitals' marks occupy 800-1000.
- Kerning (GPOS kern, ~300 base pairs): whole-pixel tucks only, computed from the bitmaps so shapes never come closer than
  two empty pixels diagonally; lowercase-lowercase pairs, digits and quotes are not kerned (keeps rn distinct from m).
- Mood: classic arcade / early computer.

## Known weak spots (honest list)
- Accented capitals extend to y=1000, above winAscent (900); fine on macOS (hhea 800/-200 used) but would clip in GDI-style clipping.
- Pixels that touch only at corners (diagonals in X, K, V, %) leave a pinch point in the merged outline rather than a seam.
- Æ, Ø, æ, ø, %, @, & are cramped at 5x7 and are the weakest glyphs; Ø shares a slash idea with a 0 (but 0 is dotted).
- Quotes/curly quotes are tiny 1-2 pixel shapes; ‘ vs ’ are distinguishable only by direction.
- Pixel look is grid-exact only at multiples of the 100-unit pixel; at odd sizes anti-aliasing blurs edges.
- Not tested in Font Book/Core Text here; verified with fontTools and Pillow/FreeType only.
