# Lyra Hand

Single-weight Regular display typeface for large on-screen lyrics (Lyra app). Original design, generated procedurally by `build_hand.py` (with shared `fontkit.py`); no existing typeface was traced or derived.

Files: `LyraHand-Regular.ttf`, `specimen.png`, `build_hand.py`, `fontkit.py`.
Rebuild: `/tmp/fontvenv/bin/python build_hand.py` (needs fontTools, skia-pathops, numpy, pillow).

## Design spec
Casual felt-pen handwriting. Pen model: slightly oblique elliptical tip (33 x 28 units at 30 degrees) with a pressure taper (thinner at stroke starts and ends), swept along Catmull-Rom skeletons; every skeleton point is jittered by a seeded RNG and the whole face has a light 0.07 lean. Single-storey a and g, open e, round off-centre i/j dots, hand-drawn numerals, tapered pen punctuation. The letters a e o s t r n i l d each have two extra drawn variants (.alt1, .alt2) with different jitter, width, rotation and some structural differences. OpenType: calt cycles base, alt1, alt2 across consecutive lowercase letters; salt maps to alt1 and ss01 to alt2; with features off the base shapes stand alone. GPOS kern pairs include the alternates.

## Technical
- unitsPerEm 1000; ascender 800, descender -200, capHeight 700, xHeight 500, lineGap 0; OS/2 winAscent 900 / winDescent 250, USE_TYPO_METRICS set (hhea 800/-200/0).
- TrueType quadratic container (glyf), outer contours clockwise, overlaps removed by boolean union; GPOS `kern` generated by an optical auto-kerner (profile-gap based, with a minimum-gap guard). Names: family "Lyra Hand", style Regular, PostScript "LyraHand-Regular".
- Covers A-Z a-z 0-9, space, the full requested punctuation set and Latin accents (accented glyphs are base letter + mark).
- Automated check (all required characters present, no empty glyphs except space, no overlaps, correct winding): passed.

## Known weak spots
- Alternates differ subtly (jitter, width, tilt, small structural tweaks), not radically new letterforms.
- calt cycling is positional (not random) so repeated words repeat the same pattern; behaviour verified on the rules, not in every shaping engine (CoreText not available in this build environment).
- Narrow, upright, fairly uniform stroke: less irregular than real handwriting; capitals G, K, Q, W are the roughest.
- Specimen draws alternates via a temporary PUA copy of the font and Pillow's basic layout (no shaping); the shipped TTF has no PUA entries.
- Curves are polylines rather than true quadratic splines.
- Not tested in Font Book/Core Text/Safari in this environment (checked with fontTools and Pillow/FreeType only); no TrueType hinting.
- The specimen is drawn glyph by glyph from the .ttf advances and GPOS kern values.
